§ colophonHow this was verified

Measurement. A bare HTML probe — one of each element, no stylesheet — was opened in Chromium 150 and every box, font and paint property was read off getComputedStyle(). The utilities above restate those values; em-based margins preserve the UA’s proportional behavior at any root size.

Diffing. Each specimen is cloned, stripped of every class, and rendered in a same-origin <iframe> that Preflight can’t reach. __audit() walks both trees in lockstep and compares ~25 properties per node, including pseudo-element content for q and the summary marker.

Known deltas. Comparison frames suppress only the body’s 8px margin so panes align. Widget interiors (dropdown arrows, checkmarks, progress fills) remain natively painted by design. Visited-link colors require matching history entries to appear. Off this reference renderer, platforms substitute their own widget chrome and serif faces.
