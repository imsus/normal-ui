# Mobile dashboard

The dashboard at phone width: key figures in a 2-column grid, the target as `<progress>`, an attention list of full-width rows, and one small chart with a table view.

**Consumer provides:** the figures, the target, the attention items and the chart data.

- Two figures per row, never three; values at 1.375rem with the comparison in `small` words.
- Attention items are full-width link rows at least 48px tall with a text tag and a `›` affordance; the whole row is the target.
- Charts fill the column width, keep one series, and always offer "Show as table".
- The top bar holds the page title as the `h1` and at most one action.
