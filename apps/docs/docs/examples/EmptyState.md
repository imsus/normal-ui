# Empty state

What a list shows when it has nothing in it: a heading that says so, one sentence on what will appear and why, and one main action.

**Consumer provides:** the heading, the explanation and the action.

- Two kinds. First use ("No orders yet") explains what the screen is for. No results ("No orders match “batik” in Returned") repeats the search and filter and offers a way to widen it.
- One button for the main action, a link for the alternative.
- Keep the page chrome (title, search, filters) in place so people can recover.
- A 1px dashed `control-border` box marks the empty area; no illustrations needed.
